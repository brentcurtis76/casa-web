A calmer place
for your mail.

Mail Desk brings account-aware inboxes, conversation reading, and a local mail cache to a quiet desktop interface.

How your data is handled

A personal prototype

The offline interface is tested with synthetic mail. Real-account validation is the next step. The current Gmail integration is read only; this project has no public installer.

01 / Accounts

Keep each inbox clear.

Separate account identities, mailboxes, and conversations. All Inboxes brings inboxes together while keeping the account visible.

02 / Reading

Save what you need.

The initial Gmail cache covers recent mail. Bodies are saved on demand so downloaded messages can be read offline; older conversation history may be incomplete.

03 / Data

A local mail cache.

Mail is stored on the computer running the app. Credentials use the desktop credential service. Read the privacy policy for storage limits, retention, and removal.
